# FCV Risk Country-Sector Briefing Generator

Produce a structured analytical briefing on recent FCV (fragility, conflict, and violence) risks for a specified country and sector, and their potential impacts on active World Bank portfolio projects.

---

## Step 1: Confirm Inputs

Check the user's message for both required inputs:
- **Country** (or sub-national region)
- **Sector** (e.g. water, education, agriculture, transport, health, social protection)

If either is missing, ask for both in a single message using the ask_questions tool. Once confirmed, proceed without further clarification.

---

## Step 2: Research

Complete external research first, then use those findings to focus internal document searches.

**External sources first:**

1. Use **web search** to build a current FCV picture for the country and sector. Follow this source preference order — prefer higher-ranked sources; use lower-ranked ones only when higher-ranked sources are unavailable or insufficient. Also search for sector-specific conditions as relevant (WASH, IPC food security, Education Cluster, Health Cluster).

   1. **ICG / CrisisWatch** — International Crisis Group conflict analysis and monthly risk ratings
   2. **Multilateral or UN sources** — OCHA, UNHCR, WFP, UNICEF, OHCHR, World Bank, UNDP, IOM DTM, IDMC
   3. **Reputable national or regional outlets** from the country — for ground-level reporting and local context
   4. **Reputable international wires or broadcasters** — Reuters, AP, BBC, Al Jazeera, VOA

   From this step, identify: the most active conflict zones or insecurity hotspots, displacement patterns, access constraints, and any sector-specific humanitarian triggers. These findings will drive the risk lens applied to internal portfolio documents in the next step.

**Internal sources second:**

2. Search the **WB Internal Knowledge base** for: `[country] FCV fragility conflict risk [sector]` — to find CPFs, CLRs, ABPEs, PADs, ICRs, IEG reports, and other operational documents. Use the geographic hotspots and risk themes identified in Step 2.1 to focus your review — e.g. if web research surfaces access constraints in a specific region, check whether project implementation sites overlap with that area.

3. Search **Projects** for: `[country] [sector] active portfolio` — to identify active lending operations. For each project found, retrieve objectives from PADs and check ISRs, Aide Memoires, and Restructuring Documents for flagged implementation issues. Assess each project's exposure against the specific risks already identified from external sources — do not conduct a generic risk review.

**Citation requirement:** Every factual claim, statistic, or situation update in the briefing must be accompanied by a hyperlinked citation. Format citations as: [Source Name, Month Year](URL). If a URL is not available for an internal WB document, include the document name and date without a hyperlink. Place each citation immediately after the claim it supports — do not cluster citations at the end. If a source was consulted but no usable URL exists, note: *[Document name, Date — URL not available]*.

Note any source gaps explicitly in the output.

---

## Step 3: Produce the Briefing

Output the briefing in exactly four sections below. Target **650–850 words** total (excluding headers and citations). Use bullet points throughout; avoid prose paragraphs.

At the top of the briefing, include a one-line header:

> **FCV Risk Briefing | [Country] — [Sector] Sector | [Month Year]**

If any finding warrants immediate task team attention, add a bold **⚠ Escalation Flag** line immediately below the header before Section 1, with a one-sentence summary of the issue and a citation.

---

### Section 1 — FCV Risk Summary (Last 3 Months)

Provide **4–6 bullets** on the most significant FCV developments, drawn from external sources gathered above. Each bullet must include:
- **What** happened (1–2 sentences)
- **Where** (region or sub-national area if available; national if not)
- **Hyperlinked citation** inline, immediately after the relevant claim: [Source Name, Month Year](URL)

If a specific source is unavailable, note: *[Source not located — based on [alternative or general context]]*

Cover at minimum: armed conflict or security incidents, displacement trends, governance or access constraints, and any humanitarian triggers relevant to the sector.

---

### Section 2 — Portfolio Exposure Analysis

Using the risks identified in Section 1 as your analytical frame, assess each active World Bank project in the specified sector and country. Draw on PADs for project objectives, ISRs and Aide Memoires for current implementation status, and Restructuring Documents for prior FCV-related adjustments. Reference IEG Reports and ICRs for lessons from closed operations where relevant. For country-level strategic context, reference the CPF, CLR, and ABPE where available.

For each project, provide:

**[Project Name] — [Project ID]** *(link Project ID to: https://projects.worldbank.org/en/projects-operations/project-detail/[Project ID])*
- *Objective:* One sentence (from PAD) — [PAD title, Date](URL or *URL not available*)
- *Current status:* One sentence (from most recent ISR or Aide Memoire) — [ISR/Aide Memoire, Date](URL or *URL not available*)
- *FCV risks to implementation:* Bullet each specific risk, tied explicitly to a finding from Section 1 where possible (e.g. "Site access in [Region] threatened by armed group activity — [OCHA, Apr 2025](URL)"). Cover: site access, contractor safety, supply chain disruption, community tensions, staff security, counterpart capacity.
- *Overall risk level:* **Low / Medium / High** *(with one-sentence rationale)*

If no specific project is identified through internal search, note this explicitly and describe the likely risk profile for a typical project of that type given the Section 1 findings.

---

### Section 3 — Potential Impacts on Delivery

Describe **3–5 concrete impacts** the identified risks could have on project delivery, disbursement, or outcomes. For each:
- Name the impact (bold)
- Link it explicitly to a specific risk from Section 1, with an inline citation (e.g. *"Linked to: armed incidents in northern [Region] — [OCHA, Apr 2025](URL)"*)
- Specify which project or project type is affected

Examples of impact types: implementation delays, cost escalation, contractor withdrawal, supervision gaps, community engagement breakdown, disbursement slowdown, fiduciary risk.

---

### Section 4 — Recommended Actions

Suggest **2–3 specific, practical actions** the task team could take within the next 30–60 days. Each action should:
- Be actionable (not generic advice)
- Name the responsible party where possible (e.g. task team leader, security focal point, government counterpart)
- Reference the specific risk it addresses, with a supporting citation where available
- Include a suggested timeline (e.g. *"within 2 weeks"*, *"before next ISR"*)

Examples: trigger the project's contingency plan, request a security assessment from the WBG Security Unit, convene a virtual supervision mission, engage the relevant UN cluster, adjust implementation modality to remote supervision, document force majeure conditions, flag in the next ISR update, or initiate a Restructuring if scope adjustments are needed.

---

**Do not fabricate sources, URLs, or project details.** If a URL cannot be verified, do not invent one — write *URL not available* instead. If data is unavailable for a specific area or time period, state this clearly: *"No recent [source type] located for [area/period]."* If a project document is not retrievable through mAI's internal search, note this rather than inferring content.
ⓘ
What makes this better than the original:
  • Designates which sources to use for the web search — and ranks them by credibility
  • Sets the exact portfolio documents to draw from (PADs, ISRs, CPFs, Aide Memoires)
  • Splits the task into clearly defined steps so mAI doesn't conflate research and writing
  • Specifies the writer, the audience, and the output format — so the result is always consistent
  • Tells the AI what to do if it does not find any project impacted
